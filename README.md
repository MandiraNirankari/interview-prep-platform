\# Interview Prep Platform



A full-stack interview preparation platform designed to help students practice DSA, track their progress, and prepare for technical interviews.



\## Features



\- User registration and login

\- JWT-based authentication

\- Secure protected routes

\- DSA question bank

\- Questions organized by topic

\- Difficulty filtering

\- Question search

\- Individual problem-solving pages

\- Code editor

\- Code execution

\- Solution submission

\- Solved-question tracking

\- Overall progress tracking

\- Topic-wise progress

\- Difficulty-wise progress

\- Mock interview module

\- Responsive dark-themed UI



\## Tech Stack



\### Frontend



\- React

\- React Router

\- Vite

\- Tailwind CSS

\- JavaScript



\### Backend



\- Node.js

\- Express.js

\- MongoDB

\- Mongoose

\- JWT

\- REST API
